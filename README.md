# Weekly KPI Report Automation

A Python tool that turns a raw orders CSV into a finished weekly report: an **Excel workbook** (Summary, Daily, Categories sheets) and a short **Markdown summary** with week-over-week changes and anomaly flags. It replaces the manual routine of filtering orders, building pivot tables and writing the summary by hand.

> **About the data:** the sample orders are **synthetic** (generated by `src/generate_sample_orders.py`). They include a few duplicate order ids and one deliberately high-revenue day so the cleaning and anomaly logic have something to find.

## What it does

1. Loads and cleans the orders (duplicates, bad dates, bad or negative values).
2. Splits the data into this week (latest 7 days) and last week (the 7 before).
3. Calculates orders, gross revenue, net revenue, average order value and return rate, with week-over-week change.
4. Flags days whose revenue is 2 or more standard deviations from the period average.
5. Writes `weekly_report.xlsx` and `weekly_report.md`.

Exact metric definitions, periods and assumptions: [`docs/metric_definitions.md`](docs/metric_definitions.md).

## Example output (synthetic data)

| KPI | This week | Last week | Change |
|---|---|---|---|
| Orders | 450 | 368 | +22.3% |
| Gross revenue | 53,867.88 | 43,702.81 | +23.3% |
| Net revenue (excl. returns) | 46,751.06 | 37,026.94 | +26.3% |
| Average order value | 119.71 | 118.76 | +0.8% |
| Return rate | 12.2% | 14.4% | -15.1% (relative) |

Anomaly flagged: 2026-10-26, revenue 20,925.83 (z = 4.98), which is the injected spike day.

## Run it

```bash
pip install -r requirements.txt
python src/generate_sample_orders.py --days 28 --out data/sample_orders.csv
python src/kpi_report.py --input data/sample_orders.csv --outdir output
python -m pytest -q        # 6 tests
```

To use your own data, provide a CSV with the columns `order_id, order_date, category, order_value, returned`.

## Scheduling it weekly

On Linux or macOS, a cron entry such as `0 8 * * 1 cd /path/to/repo && python src/kpi_report.py --input data/orders.csv --outdir output` runs it every Monday at 8:00. On Windows, use Task Scheduler with the same command.
